USED PINS:  
    Engine
A2 - LPWM  
A3 - RPWM  
B0 - Tahometer yellow  
B1 - Tahometer white  
    USART
A8 - driver toggler
A9 - USART1 TX
A10 - USART1 RX

USED TIMERS:  
T2 - count Speed every 50ms  
T3_CH3 - InputCapture mode for B0 Tahometer  
T4 - controlSystem timer  
T9_CH1 - PWM for LPWM input on engine driver  
T9_CH2 - PWM for RPWM input on engine driver
